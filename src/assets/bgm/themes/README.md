# Thèmes de combat par dresseur

Dépose ici des `.mp3` : ils sont repérés automatiquement (aucun code à toucher). Sans fichier, le jeu garde le comportement actuel (morceaux de `../` puis chiptune).

## Nommage

| Nom de fichier | Utilisé pour |
|---|---|
| `g{gen}-{id}.mp3` | un dresseur précis (liste ci-dessous), ex. `g4-cynthia.mp3` |
| `{type}-g{gen}.mp3` | repli : type de dresseur d'une génération, ex. `gym-g4.mp3` |
| `{type}.mp3` | repli : type de dresseur, ex. `elite.mp3` |
| `<nom>.low.mp3` | variante « K.O. imminent » (dernier Pokémon / ≤ 25 % des PV) ; fondu enchaîné calé sur la même position, donc **même tempo/durée de boucle que le thème principal** |
| `<nom>.win.mp3` | musique de victoire (jouée une fois) |

Types : `gym`, `elite`, `champion`, `team`, `rival`, `special` (ancien Maître). Ordre de recherche : dresseur → type+génération → type.
